Tip

  

    

      GitHub のページを右側に固定して開く
      
ボード内の PR / Issue リンクはすべて同じ 1 つのタブ (rb-viewer) で開きます。何度クリックしてもタブは増えません。

      
    
        
  1. ボード内のリンクを 1 つクリックし、GitHub のタブを開きます。
    2. 
        
  2. ブラウザの分割表示 (Chrome の分割表示、Edge の分割画面、Arc の Split View など) で、ボードを左、開いた GitHub タブを右に並べます。
    3. 
        
  3. 以降はリンクをクリックするたびに右側の表示だけが切り替わります。
    4. 
      

      
このボードより前に開いた GitHub タブは再利用されません。右側のタブを閉じた場合は、次のクリックで新しく開くので手順 2 からやり直してください。
